QUICK QUESTIONS

Context before you dive deeper.

A few useful notes on the work, the numbers, and how to verify them.

Where should I start?

Start with the selected builds, then explore the research papers and interactive case studies. The evidence and media sections provide supporting documents and activity context.

Can the projects and achievements be verified?

Yes. The portfolio links to certificates, recommendation letters, published papers, public repositories, and selected activity photographs. Each evidence item is presented with its own source link.

What does the NUS churn result represent?

The NUS project used the IBM Telco Customer Churn dataset. The tuned XGBoost model reached a 0.846 ROC-AUC. Separately, K-means identified a 1,525-customer high-risk segment; that segment is not presented as the number flagged by XGBoost.

Were the trade-execution results tested in live markets?

The reinforcement-learning paper compares the approach with TWAP, VWAP, and Almgren–Chriss in simulated limit-order-book environments. The portfolio does not present those experiments as live-trading results.

What is SignSethu?

SignSethu is an offline Indian Sign Language-to-Telugu app built with MediaPipe and TensorFlow Lite. Its model was trained using 500 self-collected samples and is linked from the project section.
