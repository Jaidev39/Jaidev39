# Jaidev Portfolio

A static, university-application portfolio for Avirineni Jaidev Chowdary covering AI/computer vision projects, quantitative research, community impact, leadership, recognition, and a searchable activity + GitHub archive.

## Included
- Existing GitHub Pages structure preserved and upgraded from V5.
- Three research entries: adversarial stress testing, liquidity-weighted trade execution, and completed historical hybrid deep-learning stock prediction research.
- The adversarial stress-testing DOCX and liquidity-weighted trade-execution PDF are included locally. The completed historical hybrid stock-prediction research has no manuscript in the supplied files.
- Public-safe evidence for GQMC 2026, YIP/RuralConnect, Plaksha Young Data Scientists, and Pan IIT Summit 2026.
- NUS evidence is described publicly while confidential recommendation/evaluation documents remain private.
- Supplied YouTube video embedded in the Media section.
- Supplied Google Drive archive linked in the Media section.
- Static HTML/CSS/JavaScript compatible with GitHub Pages.

## Deploy
The repository root is the website. In the repository's **Settings → Pages**, configure the intended deployment branch and select `/ (root)`.
