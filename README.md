## Featured Projects

### [AI Ping Pong](https://github.com/Jaidev39/AI-PING-PONG)
Interactive game controlled through real-time pose estimation. Wrist movement is
detected with PoseNet and mapped to paddle movement.

**Tech:** JavaScript · p5.js · ML5.js · PoseNet · HTML5

### [Object Detector](https://github.com/Jaidev39/OBJECT-DETECTOR)
Real-time object detection using the COCO-SSD model, with detected classes and
confidence scores displayed directly to the user.

**Tech:** JavaScript · p5.js · ML5.js · COCO-SSD · HTML5

### [AI DJ Music Web App](https://github.com/Jaidev39/AI-DJ-MUSIC-WEB-APP)
Gesture-based music interface using real-time wrist detection to control audio
playback.

**Tech:** JavaScript · p5.js · ML5.js · PoseNet · p5.sound · HTML5

### [AI Mario Game](https://github.com/Jaidev39/AI-MARIO-GAME)
Pose-controlled platform game combining gesture input with sprite animation,
collision detection, and game-state management.

**Tech:** JavaScript · p5.js · p5.play · ML5.js · PoseNet · HTML5

### [Real-Time Image Detection](https://github.com/Jaidev39/Real-Time-Image-Detection)
Computer-vision project exploring continuous visual detection and real-time
image processing.

**Tech:** JavaScript · HTML5 · Computer Vision

### [AI Video Surveillance](https://github.com/Jaidev39/AI-VIDEO-SURVILENCE)
Video-based computer-vision project exploring automated detection and monitoring.

**Tech:** JavaScript · HTML5 · Computer Vision
